先读 `AGENTS.md` §7-§9、`docs/12-文档与变更归档规范.md` 全文。

本次改动：$ARGUMENTS

执行：

1. 用 `git status` + `git diff --stat` 盘点实际改动（**不要凭记忆**）。
2. `docs/12-文档与变更归档规范.md` §2 变更记录表追加一行：序号 / 日期 / 类型 / 范围 / 摘要 / 影响 / ADR / 提交。
3. 任务卡置 `done`，回填：
   - 实际改动文件表（文件 + 增删行数 + 说明）
   - 提交信息
   - 遗留问题
4. 检查并同步 `docs/modules/*.md`：字段、接口清单、状态机、权限点、错误码是否与代码一致。
   - 发现代码与规范不符 → **以规范为准改代码**，不要改规范迁就代码。
5. 新发现的、与本任务无关的问题登记到 `docs/12` §5 遗留问题清单（不许顺手改）。
6. 规范有实质变更 → 新增 ADR + 更新 `docs/01` §6 索引 + 通知在途任务。
7. 生成 Conventional Commits 提交信息（带 `Refs: docs/modules/<模块>.md §<章节>`）。
8. 对照 `AGENTS.md` §9 自检清单逐条确认并输出勾选结果。

最后**不要**自动 commit，先把提交信息给用户确认。
