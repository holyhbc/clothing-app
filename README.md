# 服装厂 ERP（AI 全流程开发）

> 本仓库是**从零由 AI 按规范开发**的服装厂 ERP 系统。
> 覆盖：裁剪 → 打菲 → 扫码计件 → 计件工资 → 物料/成衣库存 → 销售 → 应收应付 → 记账凭证。
> **规范体系已完成（9 篇业务模块设计 + 11 篇架构决策 + 全部业务决策闭环），可以开始 P0 开发。**

---

## 快速开始

```bash
# 1. 环境（VPS 2C/12G 够用，见 docs/01 §3）
curl -fsSL https://get.docker.com | sh

# 2. 开始开发：直接对 AI 说人话，例如
#    "按 P0 地基开始，先出设计稿"
#    或用斜杠命令：/clarify  /design  /plan  /implement T-XXX-001  /test  /archive  /release
```

**开始任何开发前，AI 会自动加载 `AGENTS.md`（最高优先级规则），不需要你重复交代。**

## 业务决策已确认（2026-10-01）

| 议题 | 决策 | 依据 |
| --- | --- | --- |
| 计件单价怎么定 | **按工序定**，不分技能等级；同一款同一工序可**按生效日期调价**（历史价不可改） | [ADR-0009](./docs/adr/0009-计件单价与款号工序模板.md) |
| 工序维护 | **用户自定义增删改**，不内置枚举；被引用只能停用不能删 | [04 §7.5.1](./docs/04-数据库规范.md) |
| 款式复用 | 款号工序 + 单价可**整套复制**到另一个款号（模板），供裁剪打菲用 | [01-基础资料](./docs/modules/01-基础资料.md) |
| 员工绑定 | 扫打菲二维码 → 带出款号 → 选该款工序 → 绑定 | [04-计件 §5.2](./docs/modules/04-计件.md) |
| 一扎几件 | 由**款号工序配置**决定（工序表只给默认值） | `style_operations.bundle_qty` |
| 工资结算周期 | **用户自定义起止日期区间**；整月 / 两月一次 / 按裁剪打菲完成日截取 | [ADR-0010](./docs/adr/0010-工资结算周期自定义.md) |
| 面料成本 | **逐批（缸号）实际成本**，批次内成本恒定不可改；出库按缸选批 | [ADR-0011](./docs/adr/0011-面料批次实际成本.md) |
| 采购原材料 | 采购单录**缸号 / 颜色 / 门幅 / 重量 / 匹数 / 用途 / 备注**；返修布用 `purpose` 标记并走单独成本口径 | [ADR-0012](./docs/adr/0012-采购原材料批次字段.md) |
| 采购入库 | **审核只确认订单，不入库**；**到货登记才入库**（支持一张单分多次到货）；到货行可改实际缸号与实测门幅 | [ADR-0015](./docs/adr/0015-采购分批到货与运费.md) |
| 采购运费 | 在**采购单头**录运费单号与金额，**按本次收到的货值比例**分摊进各批次成本；不做外裁/委外 | [ADR-0015](./docs/adr/0015-采购分批到货与运费.md) |
| 裁剪尺码比例 | 按**款号 × 颜色**预置手数比例（如红色 L:XL:XXL:3XL = 1:2:2:1 共 6 手）；**每手件数每次裁剪输入**；明细 = `floor(比例 × 每手件数)` | [ADR-0013](./docs/adr/0013-裁剪尺码比例与手数.md) |
| 裁剪录入 | 比例**只作建议**，实际手数可改。三种模式：`MASTER` 按比例带出 / `UNIFORM` 统一件数 / `MANUAL` 逐行自定义（同尺码可多行不同件数） | [ADR-0014](./docs/adr/0014-裁剪明细三种录入模式.md) |
| 打菲单位 | **按手不是按件**。每手独立成码，`bundle_no` 含手序号；**一码只归一个员工** | [ADR-0016](./docs/adr/0016-打菲按手与扫码得件数.md) |
| 扫码取数 | 数量存 `bundles.bundle_qty`，**二维码只印 `bundle_no`**；扫码默认整手，可手写更小数量，**超出手数拒绝（32006）** | [ADR-0016](./docs/adr/0016-打菲按手与扫码得件数.md) |
| 裁剪行结构 | **行 = 款号 + 缸号 + 匹号**；一行可裁**多个颜色**；耗料记在行、颜色尺码出数记在明细 | [ADR-0017](./docs/adr/0017-裁剪按布批与行内多颜色.md) |
| 颜色 / 尺码 | **内置标准库**（男装/女装/童装尺码 + 基础色卡 + 码表）+ 可自由新增 | [04 §7.4](./docs/04-数据库规范.md) |
| Excel 导入导出 | **所有列表页可导出**；基础资料 / 采购单 / 裁剪单 / 销售单 / 收付款单可**三步式导入**（模板 → 校验 → 确认） | [05 §9](./docs/05-接口设计规范.md) |
| 尾单 | **尾单不入库**：所有数量向下取整到整件，余量（`balance_qty`）计入裁剪损耗；**不生成码、不计件、不入库**。布头（仍可再裁的整段布）**入库** | [09 §4.2](./docs/09-领域术语与编码规则.md) |
| 币种 | **不需要多币种**，金额一律本位币 RMB | `currency` 固定 `CNY` |
