# ADR-0019 采购运费只做台账记录，不进批次成本

| 项 | 值 |
| --- | --- |
| 状态 | Accepted（修订 ADR-0015 分摊规则） |
| 日期 | 2026-10-01 |
| 决策人 | 业务负责人 |
| 影响模块 | 裁剪 / 打菲 / 计件 / 库存 / 采购 / 销售 / 工资 |

## 背景

[ADR-0015](./0015-采购分批到货与运费.md) 当时定的是：运费按货值比例分摊进各批次成本（`allocated_cost = (采购金额 + 分摊运费) ÷ 数量`）。

业务负责人实际使用后明确要求：**运费只做记录，不摊到成本**。原因是分摊后单件成本和毛利算出来对不上供应商月度对账单，业务人员不信这个数。

## 决策

- **批次成本 = 重量 × 单价**，即 `material_stocks.unit_cost = 到货金额 ÷ 到货数量`，**不含运费**。
- 运费字段保留在 `purchase_orders.freight_amount` / `freight_no` / `freight_date`，仅用于**采购台账展示与对账**。
- 运费**不进损益、不进成本、不摊到任何单据**：不进批次成本、不进领料成本、不进成衣成本、不生成凭证行。
- 因此**成衣毛利率不扣运费**。这是业务明确接受的简化口径。
- ADR-0015 中"运费按货值比例分摊进批次成本"的结论作废，其余结论（分批到货、审核只确认、入库=到货登记、无外裁）继续有效。

### 采购台账必须展示运费

因为运费不进成本，只能靠台账体现，否则业务会以为运费丢了。供应商维度汇总卡必含 **总运费** 字段。

## 后果

**正面**：单件成本 = 重量×单价，与供应商对账单口径一致，业务能核对；取价逻辑简单。

**代价**：真实毛利被高估（因为运费没进成本）。**必须在毛利报表页头明确标注"毛利未扣除采购运费（ADR-0019）"**，避免财务误判。

**配套**：采购台账（`purchase:ledger:read`）是唯一看运费的地方，需支持按供应商+时间导出。
