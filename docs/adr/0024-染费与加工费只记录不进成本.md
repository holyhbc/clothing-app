# ADR-0024 染费与加工费只做台账记录，不进成本

| 项 | 值 |
| --- | --- |
| 状态 | Accepted（扩展 [ADR-0019](./0019-采购运费只记录不进成本.md) 的口径，不取代它） |
| 日期 | 2026-10-02 |
| 决策人 | 业务负责人 |
| 影响模块 | 采购 / 库存 / 销售 / 财务 |
| 闭环的待决项 | Q-PO-01（10-采购）、Q-ST03（06-库存） |

## 背景

[ADR-0019](./0019-采购运费只记录不进成本.md) 已裁定**运费**只做台账记录、不摊进批次成本。剩下同类问题未决：

> **染费（染色加工费）与加工费（后整、缩水等）是否也进批次成本？若进，按什么基准分摊？**

分摊会引入两个实际代价：① 单件成本与供应商月度对账单口径对不上，业务不信；② 毛利被均摊稀释，看不出哪个缸真正亏钱。

## 决策

**染费与加工费与运费同口径：只记录，不摊成本。**

### 1. 字段（单据级，与运费并列）

| 字段 | 位置 | 类型 | 说明 |
| --- | --- | --- | --- |
| `dyeing_amount` | `purchase_orders` | `numeric(18,4)` | 染费（染色加工费），默认 `0` |
| `processing_amount` | `purchase_orders` | `numeric(18,4)` | 加工费（后整、缩水等），默认 `0` |
| `freight_amount` / `freight_no` | `purchase_orders` | 既有 | 运费（ADR-0019） |

三项均为**采购单头一次录入**，不按行、不按到货次分摊；与供应商对账以**货值（重量 × 单价）**为准，费用只作记录与查询。

### 2. 成本口径（强制）

```
批次成本 = 到货行金额 ÷ 到货数量      ← 只含货值
          × 不含 freight_amount
          × 不含 dyeing_amount
          × 不含 processing_amount
```

- 三项费用**不进批次成本、不进领料成本、不进成衣成本、不进损益、不生成凭证行**。
- 因此**成衣毛利率不扣任何采购侧费用**（运费 + 染费 + 加工费）；毛利报表页头标注「毛利未扣采购运费/染费/加工费（ADR-0019 / ADR-0024）」。
- 采购单反审核时三项费用一并冲回，不残留。
- 结构上**不设分摊字段**（已删除的 `freight_allocated` 不恢复，也不新增 `dyeing_allocated` / `processing_allocated`）。

### 3. 台账展示（唯一出口）

采购台账（`purchase:ledger:read`，ADR-0022）在供应商汇总卡与到货明细中展示**总运费 / 总染费 / 总加工费**，并与应付（= 到货金额，不含费用）分列显示。支持导出。

### 4. 修改规则

三项费用与运费同规则：**已到货后仍可修改**（只改台账记录，不影响已锁定的 `material_stocks.unit_cost`），每次修改写 `document_logs`。

## 后果

**正面**：批次成本永远等于「重量 × 单价」，与供应商对账单、车间领料记录三方一致；任何缸的成本一眼看清，不会被均摊稀释；取价与成本逻辑没有分摊分支，实现最简。

**代价**：真实毛利被高估（采购侧三项费用都没进成本）。**必须在毛利报表与款式毛利页做显著标注**，否则财务会误判盈利能力。

**配套**：若日后要算「含采购费用的真实毛利」，应作为**独立报表**（管理口径）实现，把三项费用按期间归集后从毛利中扣减，**不回改批次成本**——保证账实与历史成本不可变。
