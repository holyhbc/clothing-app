# REQ-000 工期优化与复用策略（全阶段通用）

> 本卡为**全局指导性需求**，不产出代码，仅约束后续所有设计稿/任务卡的编写方式。
> 目标：在不降闸门、不改核心规范前提下，将 P1-P6 总工期从 18-25 周压缩至 10-13 周。

---

## 1. 核心优化原则

| 原则 | 执行标准 |
|------|---------|
| **脚手架优先复用** | 新模块只写业务差异，通用骨架（CRUD/权限/范围/审计/单据号/导入导出/汇总重算/乐观锁）直接 `cp -r base|cutting|stock` 改名 |
| **设计并行、实现串行** | P1-P4 设计稿同步产出（architect 并行），实现按数据依赖链串行（裁剪→打菲→计件→库存→销售→凭证） |
| **前端组件配置化** | 列表/详情/新建/编辑页统用 `ResourceList`/`ResourceForm`/`OrderedSizeItems`，仅配 `columns`/`fields`/`rules` |
| **任务卡极小化** | ≤0.5 天/卡、≤5 文件、≤500 行、单测独立可跑 |
| **测试前置介入** | Service 写完第 1 个方法，qa 同步写并发/一致性测试（闸门 3 不卡顿） |
| **文档同提交** | 代码变更 + 对应规范章节修订 + `docs/12` 变更记录 = **同一提交** |
| **非核心砍到 P6** | 会计科目体系/条码驱动/微信原生/多币种/复杂图表 → 明确写入需求卡「非目标」 |

---

## 2. 复用资产清单（每模块设计稿必填《复用资产》章节）

| 资产来源 | 可复用内容 | 适用目标模块 |
|---------|-----------|-------------|
| `base` 模块 | `DictService`/`DictRepository`/`DictRouter`/`ResourceList`/`ResourceForm`/权限注册/数据范围/审计/单据号/导入导出 | **所有单据模块**（打菲/计件/库存/采购/销售/财务） |
| `cutting` 三层结构 | `CuttingOrderService.recalc_*` 汇总重算、三层明细全量替换、乐观锁 UPDATE、行余量计算、软删/状态流转 | `bundling`（打菲单）、`purchase`（采购单）、`sales`（销售单）、`stock`（库存单） |
| `stock_ledgers`/`stock_ledger_lines` | Append-only 台账、IN/OUT/ADJUST 带符号数量、红冲链 `reversal_of_id`、批次成本快照 `unit_cost`/`amount` | `finished_goods_stocks`（成衣台账）、`wip_ledger_lines`（WIP 台账）、`arap_ledgers`（应收应付流水） |
| `OperationRate` 三档取价 | `style_no` 可空 + `NULLS NOT DISTINCT` 唯一索引、一条 SQL 档位优先+生效日取价、调价=关旧区间+插新行 | `piecework_rates`（计件单价）、`purchase_rates`（采购单价）、`sales_rates`（销售单价） |
| `AuthContext`/`apply_data_scope`/`assert_in_scope` | 四级数据范围、车间/组别/本人/全厂、软删过滤、越权防护 | **所有业务 Service** 零改动接入 |
| `mobile` 登录/布局 | 手机号验证码登录、Vant 4 布局、SSE 实时连接、扫码绑定工序页 | 员工端 H5 全套页面 |

## 6. 闸门本地预跑脚本（强制执行）

```bash
# 根目录下执行，提交前必须跑通
#!/usr/bin/env bash
set -euo pipefail

echo "=== 闸门 1+2: lint + typecheck ==="
cd backend && uv run ruff check . && uv run ruff format --check . && uv run mypy app
cd ../frontend && pnpm lint && pnpm typecheck

echo "=== 闸门 3: 单测 + 覆盖率 ==="
cd ../backend && uv run pytest -q -x --cov=app --cov-fail-under=80
cd ../frontend && pnpm test:unit

echo "=== 闸门 4: 迁移往返 ==="
cd ../backend && uv run alembic upgrade head && uv run alembic downgrade -1 && uv run alembic upgrade head && uv run alembic check

echo "=== 预跑通过，可提交 ==="
```
