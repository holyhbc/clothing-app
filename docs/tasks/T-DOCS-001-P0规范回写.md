## 目标

P0 的 15 张卡全部 `done`，但设计稿 §10.1 的九条规范回写只完成了 **2 条**（W6 落在 `04 §7.11` 的作废标注与 `§7.8.3` 三档 DDL，W9 落在 `v0.4.0-docs` 与 ADR 索引）。剩下 5 条是**代码已定型、规范还没跟上**的状态。

本卡把这 5 条补齐，并给其中两条加**机器守卫**，否则改规范这件事本身就会再次漂移。

## 为什么必须在进 P1 之前做

AGENTS §2.3 定的是「规范是唯一事实来源」。P1 的裁剪单会大量引用 `styles` 的字段口径与 `piecework_logs` 的取价口径，带着这 5 条缺口进 P1，等于让每个 P1 子代理各自猜一次 —— 而 ADR-0026 那种「列名写成不存在的 `operation_id`」的坑就是这么来的。

## 实现要点（必读规范）

- [x] **DDL 是「从迁移反向整理」的，不是原始设计**：每段都要标 `REV-2026-10 补，权威来源是迁移 000X`，不假装它是当初的设计稿
- [x] **字段口径以 `modules/01` 为准**，DDL 只负责「有哪些列、什么类型、什么约束」；两者不一致时以迁移为准并回头改 modules
- [x] 公共字段（`04 §2`）在每段 DDL 里用 `-- 公共字段见 §2` 注释带过，**不重复抄 9 个字段**（抄一遍就多一个可能不一致的副本）
- [x] 权限点落点表要写**完整链路**（定义处 / 迁移 / seed / 前端生成物 / 守卫），少一环就还会有下一个人不知道改哪
