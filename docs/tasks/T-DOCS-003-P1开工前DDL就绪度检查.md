## 目标

T-WEB-006 期间发现 `AdminLayout` 的 `<slot/>` 缺陷时，结论之一是
「**凡是有嵌套路由的页面必须有一条真用浏览器打开的 E2E**」。
这次是同一类教训的另一面：**静态守卫抓不到「照抄建不出表」**。

做法是**真建表**：把 `04 §7` 的 DDL 展开 `...公共字段` 后，按外键依赖序在临时 schema 里建一遍，
让 PG 自己说能不能建。

## 结果

| # | 发现 | 性质 |
| --- | --- | --- |
| 1 | **3 处 `REFERENCES styles(style_no)`** —— 报 `there is no unique constraint matching given keys` | `cutting_orders` / `wip_stocks` 未建（照抄失败）；**`operation_rates` 已建 → 文档落后于代码** |
| 2 | **路线图与数据模型不匹配** —— `cutting_order_lines.stock_id` → `material_stocks`（P3 表） | 业务决策，方案 A |
| 3 | `04 §7` 的 DDL 用 `...公共字段` 作占位符，是**模板不是可执行脚本** | 表达约定 |

## 决策

| # | 问题 | 决策 |
| --- | --- | --- |
| D1 | P1/P3 冲突怎么解 | **方案 A**：库存**基础表**（`material_stocks` / `wip_stocks`）提前到 P1，库存**业务**仍在 P3 |
