## 背景

`07 §7` 要求工位机页（PWA/IndexedDB）在断网时缓存待提交流水、按 `1s/2s/4s/8s/30s`
指数退避重试（最多 8 次）、页面顶部常驻「在线 / 离线（缓存 N 条待提交）」，且离线缓存
必须记 `device_id` + `scanned_at`（服务端以 `scanned_at` 归属日期）。T-PIECE-007 因
引入新运行时依赖（IndexedDB/PWA）而**刻意未做**，拆到本卡。

## 待决问题（开工前需确认）

- **Q-PW18（新增待登记）**：离线队列用哪个实现？① 裸 `indexedDB` 封装（零依赖，代码多）；
  ② 引入 `idb`（~1KB，API 友好，但新增依赖需在 `docs/01` 记一笔）；③ 换 `localStorage`
  （员工端口径，容量小、同步 API 会卡主线程）。**本卡暂不改 `docs/modules/04 §12`，
  待架构确认后登记。**
- 冲突提示（同码被他人计件）在**离线回放**时如何呈现（`07 §7` 要求"不静默丢弃"）。

## 不做
